# 🛒 বাজার দর (BazarDor)

## 📌 Project Description

**বাজার দর (BazarDor)** is a web application that helps users easily check and compare the latest market prices of daily essential products, making it easier for users to understand current prices and make better purchasing decisions in bazar.

The goal of this project is to create a simple, user-friendly, and informative platform where people can know quickly find market latet and update price.

## 🚀 Technologies Used

- **Next.js** (React Framework)
- **React.js**
- **Better Auth**
- **React text marquee**
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (Icons)
- **React toastify** (Alert)
- **JavaScript (ES6+)**
- **Git & GitHub**
- **Rest API**
- **Vercel** (Deployment)

## ✨ Key Features

### 1. 📊 Product Price Display
- Users can view current market prices
- Products are displayed with details like name, category, unit, and price.

### 2. 🔍 Category Based Filtering
- Products are organized by categories.
- Users can easily browse specific product groups.

### 3. ↕️ Price Sorting System
- Users can sort products:
  - Default order
  - Low to high price
  - High to low price

### 4. 📱 Responsive Design
- Fully responsive UI for:
  - Desktop
  - Tablet
  - Mobile devices

### 5. Bangladesh Bengali User Friendly Interface
- Supports Bengali language content.
- Designed for Bangladeshi users to easily understand market prices.
